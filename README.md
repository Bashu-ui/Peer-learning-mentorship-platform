# Peer-Learning-Platform



A platform designed specifically as an additional layer on top of Google Classroom for students to gain the best out of online evaluations. Facilitates students to look at solutions from the perspective of their peers. A platform that goes beyond learning and instils ethics and moral integrity within the community.

Feel free to contribute!


## :rocket: Tech Stack

- HTML
- CSS
- ReactJS
- Bootstrap
- NodeJS
- Express
- MongoDB


## :warning: Prerequisite

- node
- npm

To run the following on your localhost, one must download  *NODEJS* And then set the environmental as well as the system variables path accordingly.


## :cd: How to run local

```bash
# Clone the repository
# Open project in VS Code(source-code editor)
# Open the Terminal and split it into two powershells
# Go into the repository backend folder
$ cd peerlearning-backend-main
# Go into repository frontend folder
$ cd peerlearning_frontend-main
# Install folowing dependencies in frontend 
$ npm install
$ npm install @reduxjs/toolkit
$ npm install react-redux
$ npm install --save recharts
# Install folowing dependencies in backend
$ npm install
# Start the backend server
$ npm run dev
# Start frontend 
$ npm start
```


## 🤖 Chatbot Feature

The Learning Assistant is an AI-powered chatbot designed to help students navigate the platform and find relevant learning resources. Key features include:

- Course recommendations
- Resource suggestions
- Assignment help
- Mentor matching
- Skill development guidance
- Platform navigation assistance

### How to Use

1. Click the chat icon in the bottom-right corner to open the chatbot
2. Type your question or request
3. The chatbot will provide relevant responses and resources
4. Use reactions (👍, 👎, ❤️, etc.) to provide feedback on responses
5. Click on resource buttons to download learning materials

### Available Commands

- "Hi" or "Hello" - Greeting and introduction
- "Courses" or "Learning" - Course recommendations
- "Mentors" or "Guides" - Mentor matching
- "Skills" or "Abilities" - Skill development guidance
- "Help" or "Support" - Platform assistance
- "Assignments" or "Tasks" - Assignment help
- "Resources" or "Materials" - Learning resources
- "Feedback" or "Review" - Provide feedback
- "Schedule" or "Time" - Session scheduling
